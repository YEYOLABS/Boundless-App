╔══════════════════════════════════════════════════════════════════════╗
║                         TECHNICAL DETAILS                            ║
╚══════════════════════════════════════════════════════════════════════╝

Root Cause:
- Missing permission request before accessing camera/gallery
- Wrong mediaTypes syntax: ['images'] instead of MediaTypeOptions.Images
- No error handling

Fix Applied:
- Added requestMediaLibraryPermissionsAsync() before gallery access
- Added requestCameraPermissionsAsync() before camera access
- Fixed mediaTypes to use ImagePicker.MediaTypeOptions.Images
- Added try-catch error handling
- Added user-friendly error alerts
- Added Android 13+ permission support
